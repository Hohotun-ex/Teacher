# Простий сайт викладача

Це спрощена студентська версія персональної сторінки викладача.

## Файли
- `index.html` — структура сторінки
- `style.css` — просте оформлення
- `script.js` — мобільне меню та демонстраційна форма

## Що можна замінити
У `index.html` замініть ПІБ, кафедру, контакти, фото, дисципліни, розклад і посилання на реальні дані.
